# DESIGN — Metrics data layer (phase 1, architect)

## Layering (imports flow downward only)
`config/metrics.ts` (+ `metricsCodes.ts`, `metricsText.ts`, re-exported by `metrics.ts`) → `types.ts` (+ `outputTypes.ts`, `rowTypes.ts`, `rawTypes.ts`, all re-exported by `types.ts`; type-only) → `window.ts`, `compute/*`, `query/*` (pure; compute may import `window.ts`) → `source/MetricsSource.ts` (port, `LoaderDeps`, `Loader<R>`) → `shared/*` → `loaders/*` → `catalogue.ts` → `loadCard.ts` → `hooks/*` → `index.ts`. `source/osdk` and `source/fake` implement the port and are imported only by `hooks/MetricsSourceContext.ts`, `index.ts` and tests. Unions (`Caveat`, `CardId`, `StageId`, `WindowKey`, `BreakdownDimension`, …) are derived in `types.ts` from the config tuples (`typeof CAVEATS[number]`), so config never imports `src/data`. `MetricsConfig` is an explicit interface in config; `METRICS_CONFIG` is the default; loaders read `deps.config`, sources read `ctx.config`. Static texts and card metadata (`CAVEAT_TEXT`, `STAGE_LABELS`, `CARD_META`, …) are imported directly.

## Specs (query/specs.ts) — four closed set types, business names only
`ItemSet` {all, openInWindow, filtered, ofEvents, ofOpenAlerts, ofRisk, intersect/union/subtract} · `EventSet` {all, ofItems, ofOpenAlerts, where(EventFilter), set ops} · `OpenAlertSet` {all, ofItems, ofEvents, where(OpenAlertCondition), set ops} · `RiskSet` {all, ofItems, where(RiskCondition), set ops}. `EventFilter = { predicates: EventPredicate[] (OR), window: Window | null }`, predicates `viewed|action|writeback|human|opened|closed|lifecycle`. Group-by-only rule is structural: events filter only by predicate+window; `OpenAlertCondition` only on `routingPersona|priority|escalated`; `VerdictFilter` only mode+window. Group fields: `EventGroupField` = `queueFilter|routingPersona|alertType|priority|actionType|writebackType` (→ persona, riskType, priorityAtEvent, eventType), `OpenAlertGroupField`, `ItemGroupField = ItemDim`, `AppUsageGroupField = "queueFilter"`. `query/build.ts` (Agent B) builders: `allItems, openItemsInWindow(w), withItemFilters(set,f), events(preds,w,f)` (pivot from filtered items iff filters set), `openAlerts(f)` (aofSet), `itemsWithEvent(preds,w)`, `itemsWithOpenAlertWhere(f,cond)`, `escalatedEvents(v,preds,w)`, `closedNotOpenNow(w,f)` = `subtract(events(closed,w,f), ofOpenAlerts(ofEvents(·)))`, `openedEventsOfItemsOf(events)`, `touchedEventsChain(w,f)` = `where(ofItems(ofEvents(events(human,w,f))), [lifecycle,human], null)`, `riskAll(f)`, `riskWorked(w,f)`, `riskWhere(set,cond)`, `itemsOfRisk(set)`.

## Port (source/MetricsSource.ts) — 16 methods, one server call each (id lookups chunked)
Aggregates: `countItems`, `countItemsBy(dim)`, `countEvents(distinct actor|alert)`, `countEventsBy`, `countOpenAlerts`, `countOpenAlertsBy`, `countRisk`, `countRiskByScoreRange(ranges)`, `countAppUsers(w)`, `countAppUsersBy`, `countVerdictsBy(VerdictFilter)`. Rows (`Paged<T> = {rows, capped}`): `fetchEvents`, `fetchOpenAlerts`, `fetchItems`, `fetchItemsByIds`, `fetchVerdictsByIds`. `SourceCtx = {signal, onProgress?, config}`; grouped calls use `config.MAX_GROUPS`; callers add `truncated` when `rows.length === MAX_GROUPS`.
**Seam (rule 9):** a future `fetchAlertLifecycles(filter, ctx): Promise<Paged<AlertLifecycleRow>>` replaces L2's fetch + `compute/alertLifecycle.ts` (comment in the port). `shared/touchedAlerts.ts` keeps its signature `loadTouchedAlerts(window, filters, deps) → {rows: AlertLifecycleRow[], capped}`; only its body switches. The 4.2 not-worked fetch switches the same way.

## Shared loaders (never acquire the app semaphore; memo = one in-flight promise per key; cleared by `clearMetricsCache`)
- **L1** `loadHumanEvents(w,f)`: `fetchEvents(events([human],w,f))`. Key `L1|w.key|hash(f)`.
- **L2** `loadTouchedAlerts(w,f)`: L1 + `fetchEvents(touchedEventsChain(w,f))` + `fetchOpenAlerts(ofEvents(events([human],w,f)))` → `alertFactsOf` per touched id. Key `L2|w.key|hash(f)`.
- **L3** `loadOpenAlerts(f)`: `fetchOpenAlerts(openAlerts(f))`, `fetchEvents(where(ofOpenAlerts(openAlerts(f)),[opened],null))`, `fetchItems(ofOpenAlerts(openAlerts(f)))`; three memos `L3a|L3o|L3i|hash(f)`.

## loadCard flow (never throws)
1. `window = resolveWindow(selection.window, now)`. 2. breakdown not in registry for (card, view) → `error`, `breakdown-not-allowed`. 3. `CARD_META[c].stub` → `blocked` with stub reason/unblockedBy/caveats, no calls. 4. any `CARD_META[c].requires` key whose `config[key] === config.PLACEHOLDER` → `blocked`, `needs-integration-value`, `INTEGRATION_UNBLOCKED_BY[key]`. 5. cache hit → derive synchronously. 6. else semaphore(APP_SEMAPHORE_SLOTS) → `load` → cache `{output, computedAt}` → `derive(raw, selection)` → `MetricResult{ status: loader.status, data, caveats: mergeCaveats(loader, derive, every stage of total and groups), computedAt, window, progress }`. Errors → `status: "error"`. `catalogue.ts` types each entry as `{ load: Loader<CardRaw[C]>; derive: Derive<CardRaw[C], CardOutput[C]> }` so `loadCard<C>` returns `MetricResult<CardData<CardOutput[C]>>` without casts.

## Assumptions (for QUESTIONS.md)
Assumed: (A1) raw keys hold only fields a card reads: 4.1 omits filters (R3), 4.5 omits window, itemFunnel alone has view — same invalidation as spec §11 without redundant refetches. (A2) 3.1 with a breakdown keeps the 14 value calls besides the 14 grouped calls, so bucket totals and `other` include items with a null dimension value (spec says "replace"; replacing would drop them). (A3) `EventGroupField` uses breakdown names instead of AlertHistory apiNames, to keep apiNames out of specs; the §6 mapping holds. (A4) L1 rows are `AlertEventRow` (eventSource nullable at the source); `HumanEvent` stays exported as the spec type. (A5) 2.1 `build-stamp` in both views when window key is 7. (A6) `MAX_GROUPS` comes from `ctx.config`, not a call parameter; the fake keeps the largest groups when truncating. (A7) 4.1 worked ids use `fetchItems` (ItemRow fields, not only salesOrderId). (A8) loadCard validates the breakdown before the blocked checks. (A9) `ageingBacklog` result `window` = the resolved selection window (unused by the card). (A10) `window.ts` is pure and importable by compute.
Blocked: `ALERT_APP_ID` (userFunnel), `VERDICT_DATE_PROPERTY` (otifOutcome) = `"<to be set at integration>"`.
